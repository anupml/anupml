## Selected work

I learn by shipping, not by collecting tutorials. Recent projects span:

- **Neural network internals** — an autograd engine and backpropagation implemented from scratch, then character-level language models built up from bigram counts to a multi-layer perceptron
- **Tabular ML** — feature engineering, pipelines, and gradient boosting on Kaggle competitions (XGBoost, LightGBM)
- **Neural networks** — classifiers and regressors in PyTorch and Keras, with regularization and initialization experiments
- **Unsupervised learning** — clustering and dimensionality reduction, including PCA implemented from scratch and verified against scikit-learn
- **NLP** — text classification comparing TF-IDF and embedding-based approaches

You'll find these in the repositories below — all works in progress, improving with each commit.
